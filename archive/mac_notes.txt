Something like right click in Windows: control + right click (or double finger click? You can change in Trackpad in Setting)

Paste without formatting: Press Option (⌥) + Shift + Command (⌘) + V

Search function for everything: 
Option 1: the search logo in the top right corner
Option 2: command+space, then use command+return to go to the location

To move things from location A to B: 
Option 1: drag and drop
Option 2: command+C for copying, option+command+V for moving

Show all the running APPs: command+ Tap
Quit the APP: command+q
Close the APP but the APP is still run in the background: click red x

Force Quit some software: Press Command (⌘) + Option + Escape

Screen shot: Command+shift+4
Full screen shot: Command+shift+3

Time machine function: show the version of your things in the computer

Zoom in: CMD and +
Zoom out: CMD and -

In Positron, batch # some lines of codes: cmd + /
