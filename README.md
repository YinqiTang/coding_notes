My personal coding notes for Python, R, SQL, Git and the tools around them, so I don't have to look the same thing up twice. This folder is also an Obsidian vault, so the notes read best when opened in Obsidian.

**The notes:** All notes live in the `notes` folder.

**Table of contents needs a plugin:** Each note starts with a `table-of-contents` block. It only turns into a clickable list in Obsidian with the `Automatic Table of Contents` plugin enabled (it is installed per vault). On GitHub or in other viewers it shows up as an empty code block.

**Placeholders:** Names like `table_1`, `strain_id` and `my_working_branch` are stand-ins. Swap in your own names before running anything.
